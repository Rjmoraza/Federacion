# Federación

Proyecto de documentación para la constitución de una federación de asociaciones (segundo grado) en Costa Rica, sector cultura/producción audiovisual.

## Contenido

- **Estatutos.md** — Borrador de estatutos de la federación.
- **normas/** — Normativa de referencia (Constitución Política, Ley de Asociaciones).
- **utils/** — Material de trabajo: agenda, matriz de riesgos de figuras no formales, datos de asociaciones en Costa Rica.
